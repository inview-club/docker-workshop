# Первый контейнер

Запускаем nginx и публикуем его порт 80 на порту 8080 компьютера. Порт 8080 должен быть свободен, Docker — запущен.

```bash
# Запуск контейнера в фоне, доступ только с этого компьютера
docker run -d --name web-demo -p 127.0.0.1:8080:80 nginx:stable

# Проверка HTTP-ответа
curl http://localhost:8080

# Просмотр логов
docker logs web-demo

# Проверка конфигурации nginx внутри контейнера
docker exec web-demo nginx -t

# Остановка контейнера
docker stop web-demo

# Просмотр контейнеров, включая остановленные
docker ps -a

# Удаление остановленного контейнера
docker rm web-demo

# Просмотр образов: образ nginx остаётся после удаления контейнера
docker images
```

`-d` запускает контейнер в фоне. В `-p 127.0.0.1:8080:80` первый порт относится к компьютеру, второй — к контейнеру.

После остановки контейнера порт 8080 освобождается для следующего задания.
